# 名剑查询

适用于 AstrBot 4.16 至 4.x 的试用版。插件直接请求 [剑网三 PVP 查询站](https://jx3.unua.top/) 的公开 JSON 数据，用 Pillow 在本地生成聊天图卡。

各版本新增功能、修复和使用方式变更见 [更新日志](CHANGELOG.md)。

图卡采用水墨卷轴样式。水墨插画和标题字体随插件打包，正文使用 Noto Sans SC。标题字体的授权见 `fonts/OFL-MaShanZheng.txt`。[原字体 Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng)

## 安装

1. 在 AstrBot 管理面板的「插件」页从链接安装，填入 `https://github.com/ink2421665373/astrbot-plugin-jx3mjdh.git`。也可从文件安装，上传插件 ZIP。安装后先发送 `/名剑帮助`。
2. 覆盖升级时保留原插件名 `astrbot_plugin_mingjian`，让 AstrBot 安装插件依赖 `Pillow` 后重新加载。安装包自带字体，查询需要 AstrBot 能连接原站及原站使用的西山居图标 CDN。
3. 发送 `/剑三 战绩 区服 角色名` 验证取数和出图。可在战绩图下回复对局序号，继续查看详细数据和回放。

示例采用 AstrBot 默认的 `/` 唤醒前缀。

手动指令和编号查询会同时启动「查询中」提示与取数，结果按顺序随后发送。自然语言查询先提示，再识别指令。QQ OneBot 等支持引用的适配器会回复触发查询的指令或序号。

### 在 WebUI 接收更新提示

1. 在 AstrBot WebUI 的「插件市场」中打开插件源设置，添加「名剑查询插件源」，地址填 `https://raw.githubusercontent.com/ink2421665373/astrbot-plugin-jx3mjdh/main/plugin-market.json`。
2. 已安装的用户在插件列表中打开「名剑查询」的「更换插件源」，选择刚添加的源并保存。首次安装也可以在该源中直接找到名剑查询。
3. 刷新插件列表。当插件源中的版本高于已安装版本时，WebUI 会显示更新入口。

后续升级请优先用插件卡片的「更新」。再次「从链接安装」或「从文件安装」会将安装方式改为仓库或上传，安装后到「更换插件源」重新绑定，才能继续收到市场更新提示。

如果部署机器访问 GitHub Raw 超时，可将源地址填为 `https://cdn.jsdelivr.net/gh/ink2421665373/astrbot-plugin-jx3mjdh/plugin-market.json`。发布后先核对实际绑定的源是否已返回新版。CDN 仍返回旧版本时，刷新 WebUI 也要等源更新后才能看到提示。

## 直接用原生聊天查名剑

`战绩 唯满侠 双绛` 可直接查询，群聊无需 @。也可按 AstrBot 的方式唤醒机器人，例如 `@机器人 查一下人参王的战绩` 或 `@机器人 查询一下人参王的战绩`。这些写法沿用原有战绩和角色昵称流程，无需调用对话模型。需要日期或场数等筛选时，可用 `/剑三 战绩`。

`@机器人 查一下奶妈的心法强度排行` 由 AstrBot 当前会话的对话模型识别。模型调用名剑工具后，插件按治疗类型生成强度榜，用户未指定的条件沿用默认值。私聊按 AstrBot 的唤醒设置发送即可。

`@机器人 dps强度排行` 或 `/名剑 查一下输出心法强度排行` 会让模型查询输出心法强度榜。`DPS` 和 `dps` 都表示输出。

插件提供原生工具 `mingjian_query`。使用支持工具调用的 AstrBot 对话模型。若当前人格限制可用工具，在该人格的工具权限中允许 `mingjian_query`。群聊沿用 AstrBot 的唤醒设置。

- `查一下花间游的 3v3 排行榜`
- `看看云晚归最近 5 场战绩`
- `给我花间游的奇穴图谱`

模型在明确请求剑三数据时调用工具，插件直接回复图卡和编号菜单。打法讨论走正常对话。图卡菜单可回序号、回 `0` 返回上一层。工具用当前会话的对话模型识别意图，使用下方的独立自然语言指令属于另一种入口。

## 自然语言指令

打开「插件 → 已安装 → 名剑查询 → 插件配置」，开启「自然语言查询」，在「自然语言模型」中选择 AstrBot 已配置的对话模型并保存。固定模型留空时跟随当前会话的对话模型。插件使用 AstrBot 已保存的模型设置。

「AI 响应超时（秒）」可填 1–300 的整数，默认 30 秒。保存后会应用到新的自然语言查询，模型服务自身的超时仍然生效。

模型调用失败时，插件会根据 AstrBot 返回的错误区分模型未加载、接口认证或权限、限流或额度、连接或 TLS、超时等情况。日志会记录失败阶段、耗时、HTTP 状态和异常类型。

- `/名剑 查梦江南奶花的 3v3 前 100 排行榜`
- `/剑三 问 给我花间游第八重的第二套奇穴`
- `/名剑 复盘唯我独尊的云晚归最近 20 场 2v2 组排`

发出指令后，所选模型接收这句话来识别一条指令及其参数，查询结果和图卡由插件生成。查询角色时请在话里写明角色名或推栏个人 ID。要继续查看菜单，按提示直接回复序号。

## AI 锐评

在「扩展功能 → 名剑查询」开启「AI 锐评」，选择一个 AstrBot 已保存的人格并保存。锐评默认关闭，关闭后会保留所选人格。插件读取该人格的系统提示词用于锐评语气，沿用页面的对话模型和超时设置。锐评可单独开启。

发送 `/剑三 战绩复盘 角色名` 等指令，回复图卡消息中「AI 锐评」对应的序号，模型会根据当前图卡的公开数据点评。适用于战绩、对局详情、回放、战绩复盘和角色总览。锐评完成后可继续使用原编号菜单。

## 在 WebUI 配置别名

支持插件可视化视图的 AstrBot 版本，可从 WebUI 侧栏「扩展功能 → 名剑查询」管理两类别名、自然语言开关、模型和 AI 响应超时。独立页面与插件配置表单共用设置。

在 AstrBot WebUI 打开「插件 → 已安装 → 名剑查询 → 插件配置」，选择「心法别名」或「服务器别名」，新增一条映射。填写原站名称，再填写对应的别名。多个别名可用换行、空格或逗号分隔。

- 心法全名填 `花间游`，别名填 `花花，万花DPS`。保存后可用 `/剑三 奇穴 花花`、`/剑三 排行 万花DPS` 或 `/剑三 配置总览 花花`。阵容检索里用空格隔开多个心法，例如 `/剑三 配置总览 检索 花花 剑纯 奶花`。
- 服务器名填 `梦江南`，别名填 `梦服，江南`。保存后可用 `/剑三 战绩 梦服 角色名` 或 `/剑三 排行 梦服`。

别名查询显示原站名称。同一类里的别名应只对应一个目标。拉丁字母大小写和全角、半角写法可以混用。保存后，AstrBot 热重载插件，新的查询即可使用更新后的映射。

## 角色昵称

打开「扩展功能 → 名剑查询 → 角色昵称」，点击「添加关联组」。左侧一行填一个昵称，右侧可用「添加角色」录入多个区服和完整角色名。每个昵称都对应本组全部角色。例如同组填「阿墨」和「师父」，再添加两个角色，用任一昵称都会列出这两个角色。

管理页可按昵称、区服或角色名搜索关联组，也可移除单个角色或整组。旧版记录会按原昵称显示在组内，保存后采用新的分组格式。

- `/剑三 战绩 阿墨 33 5场` 会列出阿墨的角色，附上「按角色原名“阿墨”查询」。回复序号，沿用 3v3 和 5 场筛选。
- `/剑三 战绩复盘 梦江南 阿墨 组排 20场` 先筛选梦江南的角色。若该区服没有配置角色，仍可选择按原名查询。
- `/剑三 角色总览 阿墨` 或直接说「查一下阿墨最近 5 场战绩」。昵称中有空格时，手动指令用双引号包住昵称。

昵称候选为本地配置，保存后对新的查询生效。候选菜单可按序号选择或回退，选定后再请求原站。

编号菜单只接受发起者在同一个聊天里的回复，有效期 2 分钟。过期后首次回复序号会提示重新发送查询指令。遇到下一级菜单时再次回复序号即可。普通查询仍可省略参数并使用默认值。

误选后回复 `0`，收到「已返回上一级」和上一层菜单后可按原序号重选。可连续回 `0`，每次退一级并重发对应菜单。完整结果图也可以回退，最多保留最近 16 级菜单。输入超出范围的序号时，可直接在当前菜单重选。

排行榜左侧单独显示可回复的序号。回复角色旁的序号查询战绩，榜单名次一列显示实际排名。统计和翻页选项继续排在图卡下方。

查询图卡和含名字的编号菜单会在角色名、心法名及配队成员名前显示原站对应图标。原站数据没有提供可识别心法时显示问号。

## 查询方式

- 同一插件实例串行取数。每个原站数据请求结束后至少隔 2 秒才发下一个请求，一个新查询取数结束后至少隔 4 秒才开始下一个新查询。重复请求可共享正在执行的取数或复用 90 秒内的结果，部分数据有更长的缓存时间。出图单独排队，每次渲染一张图，图标同时下载最多两个。同一份结果可复用已生成的 PNG，图标下载失败的图卡会在下一次出图时重试图标。
- 已有效缓存的结果可以直接用于回复。图标成功下载后保存到插件数据目录的 `icon-cache`，重启后可复用 7 天内写入的图标，最多保留 256 个缓存文件。
- 常用心法图标随插件打包，优先从本地加载。其他图标沿用下载和缓存机制。
- AstrBot 日志中搜索「名剑耗时」可看到进度提示、取数排队、取数、出图和发送阶段的耗时。发送阶段从插件生成结果到 AstrBot 发送流程结束，包含平台适配器的处理时间。
- 与原站连接中途断开或响应提前结束时，等满请求间隔后重新连接一次。AstrBot 日志区分取数、图标加载和出图故障。
- 搜索「名剑取数失败」可查看网络故障发生的阶段及 TCP 对端地址。代理转发时，TCP 对端是代理的地址。
- 门派、技能、奇穴和阵法共用门派数据，在 AstrBot 插件数据目录保存最后一次成功结果，重启后可继续使用。一小时内复用缓存，超过一小时后尝试刷新。遇到临时网络故障、HTTP 429 或原站 5xx 时，可使用最近 24 小时内保存的资料。使用恢复或兜底缓存时，图卡或编号菜单会标注原保存时间（北京时间）。
- 排行榜周期列表正常缓存 10 分钟。临时故障时可复用最近 24 小时内保存的周期列表，保存日期用于解释历史周次。省略周期查询时，周期列表无法取得或缓存已经跨周，可以继续查询默认榜单。指定周次时，按已确认的周次查询。
- 原站返回 HTTP 429 时暂停新数据请求至少 60 秒。若原站给出更长的等待时间，则按该时间暂停。编号操作遇到限流时，原菜单保留到冷却结束后 2 分钟，可再次回复该序号。已缓存的复盘可以保留本轮成功补查的场次。
- 奇穴名称、说明和图标取自原站门派数据。套路名称和默认点法采用本版本随包发布时的原站推荐快照，当前点法在图里高亮。
- 走势使用原站已有的榜单快照。历史某周可能只有一个观测点。较首日需要该心法在首日有人数记录。
- 对位胜率来自原站历史汇总。点「查公开对局样例」后，插件最多核对 10 场代表对局，只显示阵容符合条件的样例。
- 对局详情和回放写入缓存前校验对局编号。回放导出沿用原站的 JSON 格式，附件超过 4 MB 时请在原站回放页下载。回放图按实际高度判断能否生成，超出 60,000 像素高时可按玩家或击杀点筛选。图上横轴为原站伤害采样点，技能流水时间为局内秒数。
- 多场战绩复盘使用公开战绩和对局详情。战绩列表用于计算胜负与战后积分，阵容、队友和奇穴只统计能匹配到该角色的公开详情。胜率分母为能确认结果的对局。
- 对局详情临时失败时，复盘保留已读取场次，并提供「重试失败场次」。补查计入原样本，保留已选的排队筛选。在原查询的缓存有效期内，重发指令也能看到更新后的详情覆盖。
- 公开对局没有实际排队标记。样本里相同完整队伍出现至少两次则列为疑似组排。至少有两场完整样本且分析结束后，完整队伍只出现一次列为散排候选。详情不全、只有一场完整样本或暂不能归类的对局留在未知。不同日期与场数会改变分类。切换筛选复用已有样本，胜负、积分、奇穴及单场入口使用同一组筛选结果。
- 角色总览的雷达按原站评级画图，最多显示 8 项有评级的指标。数值、评级和已有名次列在下方，空缺项以「—」显示。
- 随包提供 [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 中文字体，许可见 `fonts/OFL.txt`。
